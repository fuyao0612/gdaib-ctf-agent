# 本地安全知识库（RAG）

御网智元在 SQLite 中保存知识文档和确定性切分后的片段。V1 使用本地中英文稀疏检索，
不调用额外的 Embedding 服务，因此导入和检索不会把整份文档发送到第三方。

## 使用方法

1. 打开“设置中心 → 扩展能力 → 本地安全知识库（RAG）”。
2. 使用内置的 CTF、应急响应、漏洞分析和静态逆向知识基线，或粘贴有权使用的文档。
3. 为文档选择适用场景和标签。
4. 只有确认内容可以发送给当前模型服务时，才开启“允许命中片段进入模型上下文”。
5. 在“检索预览”中输入问题，检查命中的标题、片段、相关度和 SHA-256。
6. 新建任务时选择安全场景。Run 开始时会检索并固化最多四个片段。

## 信任与审计

- RAG 内容与附件、网页和工具输出一样，始终是不可信资料，不能修改系统策略或授权。
- 每次 Run 保存文档 ID、片段 ID、来源 URI、内容 SHA-256、相关度和当时的片段正文。
- 文档后续更新不会改写历史 Run；重试同一 Run 时继续使用原快照。
- 运行审计和 Markdown/JSON 报告都会列出本次命中的知识来源。
- 未开启 Provider 上下文许可的文档只保存在本机，不参与任务检索。

关闭“允许命中片段进入模型上下文”只影响之后创建的 Run；既有 `KnowledgeMatchSnapshot` 保留当时的来源 URI、片段正文和 SHA-256，不会被文档设置的后续变更改写。测试覆盖该知识检索开启/关闭消融行为。

## 当前边界

V1 面向单机、小中型知识库，使用可复现的稀疏词项相关度，不提供语义向量召回、OCR、
远程网页抓取或目录自动同步。后续若增加 Embedding，必须单独配置模型、数据分级、批量重建、
向量版本和删除传播，不能复用聊天 Provider 的隐式权限。
