# 场景指南

CTF 结果必须是 `flag` TaskResult，绑定证据，并由本地 Judge 或已记录的平台结果验证。格式匹配不是正确性验证。

应急响应结果使用 `indicator`，稳定字段为 `iocs.ips`、`iocs.domains` 与 `iocs.hashes`，并引用输入日志 Artifact。漏洞分析使用 `vulnerability`，记录文件、行号、类别、严重性和修复建议。逆向静态分析只读取受控文本或无害样本，不执行样本；记录样本哈希、指标、算法和偏移或来源。

所有场景都应保存输入、计划、工具调用、证据、验证器输出、报告和失败轨迹。不得新增未授权扫描、攻击工具或未知程序执行。
