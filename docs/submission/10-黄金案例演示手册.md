# 黄金案例演示手册

1. 用 `docker compose -f compose.yaml -f compose.golden-demo.yaml up -d --build` 启动隔离工作台，在 `http://127.0.0.1:18080` 配置真实 Provider；另开终端启动 `python scripts/golden_web_lab.py --port 8088`。
2. 运行 `python scripts/run_golden_demo.py --case A-ctf-attachment --timeout 240`。它经正式附件与消息入口生成 Run；展示无效候选分支、工具链、Evidence 和 Judge。
3. B：授权 `http://127.0.0.1:8088/`，要求自主探索；展示首页 -> status -> robots -> notes -> 受控请求头 -> 解码 -> 验证。
4. C：上传 hostile-notes.txt，要求总结；展示策略拒绝、授权未扩大、合法摘要继续、报告中的恢复依据。
5. 下载轨迹和报告，核对 Run、Provider/Tool 快照与验证状态。禁止展示答案配置或访问公网。

## 截图与证据清单

- 启动页：`18080`、Provider/Agent 就绪状态，不截取密钥。
- A：上传类型摘要、工具调用序列、至少一个无效候选/重规划、Judge 结果和报告下载页。
- B：靶场终端只显示 `127.0.0.1:8088`；轨迹依次出现首页、status、robots、notes、受控 Header、解码和验证。
- C：`policy_checked` 拒绝事件、`warning` 恢复事件、授权快照、合法摘要结果；不显示 hostile 文本中的秘密样例。
- 评测中心：`/api/v1/evaluations` 和 `/statistics` 的记录数、状态、耗时、工具调用和失败分类；只展示脱敏摘要。
