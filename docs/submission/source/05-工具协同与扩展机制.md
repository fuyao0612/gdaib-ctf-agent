# 工具协同与扩展机制

所有工具遵循 `ToolSpec`、输入/输出 Schema、风险、权限、超时、错误码和幂等契约，统一经 Registry、PolicyEngine、Executor 执行。内置 CTF 工具可串联 Artifact；MCP 仅允许管理员白名单命令或受控 HTTPS，禁止 Shell 解释器。

Run 启动时会依据任务场景、工具 capabilities 和已有 Artifact 类型生成候选工具清单，再由 Agent 自主选择并记录公开理由；新增 `consumes`、`produces`、前置条件与失败替代能力不会改变这一决策边界。

新增工具需实现 SDK Plugin、补契约/越权/失败测试，并声明可处理的 Artifact 类型；Run 启动时冻结工具快照。
