# 初审差距矩阵

本文件记录作品与官方评分维度的对应关系，便于初审复核和后续决赛适配。分数区间只是基于现有证据的内部估计，不代表评委预判。

| 维度 | 当前实现 | 可复核证据 | 当前边界 |
| --- | --- | --- | --- |
| 任务理解与执行设计 | TaskSpec、规划、重规划、上下文记忆 | Run 轨迹、AgentEngine 测试、acceptance 用例 | 决赛未知题型尚未覆盖 |
| 系统架构与工程实现 | FastAPI、SQLite、React、Compose、Windows 脚本 | pytest、前端测试、Docker 健康检查、doctor | 公网认证需由部署环境提供 |
| 决策逻辑与可解释性 | Event、ExecutionStep、Evidence、Report、检查点 | trajectory、报告、恢复和策略测试 | 不展示隐藏思维链，仅展示公开摘要和事实 |
| 工具协同与扩展 | ToolSpec、Registry、Executor、插件、MCP | 工具契约、工具调用事件、SDK 文档 | 不支持任意 Shell 和未授权目标 |
| 创新与应用价值 | 不可变 Run 快照、证据绑定、独立验证 | Local Judge、证据矩阵、评测报告 | 未配置 Provider 时不宣称真实模型成绩 |

## 能力边界

系统只处理明确授权的附件和本地目标；不提供任意 Shell、未授权公网扫描、自动攻击或外部平台提交。真实成绩必须来自脱敏 Run、trajectory、report 和 evaluation record。
