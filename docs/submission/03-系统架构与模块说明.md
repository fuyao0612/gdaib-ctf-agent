# 系统架构与模块说明

## 1. 总体架构

```text
React Web
  ↓ REST / SSE
FastAPI API
  ↓
AgentEngine + LangGraph 状态图
  ├─ Task Brief / Planner / ActionSelector
  ├─ PolicyEngine / Budget / Approval
  ├─ ToolRegistry / ToolExecutor / MCP Client
  └─ Verify / Finalizer / Report
        ↓
SQLite 审计库 + Artifact 文件存储
```

## 2. 模块职责

| 模块 | 作用 | 关键位置 |
| --- | --- | --- |
| API 层 | 任务、消息、运行控制、报告和评测接口 | `apps/api/routes/` |
| Agent 层 | 计划、动作、观察、重规划、验证、恢复 | `src/yuwang/agent/` |
| 控制模型 | Task Brief、Plan、Action 和结构化输出契约 | `src/yuwang/control/` |
| 策略层 | 授权目标、权限、风险、预算和输入信任边界 | `src/yuwang/policy/` |
| 工具层 | ToolSpec、注册、选择、执行、插件和 MCP | `src/yuwang/tooling/` |
| 存储层 | Run、事件、ToolCall、Artifact、Evidence、报告和检查点 | `src/yuwang/storage/` |
| 结果层 | TaskResult、证据绑定和服务端验证状态 | `src/yuwang/results/` |
| 评测层 | 本地任务包、私有 Judge、评分和结果导出 | `src/yuwang/evaluation/` |
| 前端层 | 场景入口、任务时间线、活动流、审计和设置 | `apps/web/src/` |

## 3. 关键工程约束

- Run 创建后冻结 TaskSpec、Provider、Profile、工具和授权快照；
- 工具不能绕过 Registry、PolicyEngine 和 Executor；
- 外部内容只作为不可信数据进入上下文，不能提升为系统指令；
- 非幂等或状态不确定调用不会被恢复逻辑自动重放；
- 原始审计事实与展示摘要分离，报告和 UI 只读取持久化事实。
