# PPT 逐页大纲（15 页）

1. 封面：御网智元、赛题名称、版本与统一工作台地址。
2. 初审回答的问题：自主规划、受控工具与可解释验证。
3. 可审计任务闭环：从用户目标到证据、验证和报告。
4. 不可变 Run 快照：固化模型、Agent、授权、工具、目标与附件摘要。
5. 自主规划与动态调整：`dynamic + verified` 默认策略及失败重规划。
6. 工具协同与扩展：统一 ToolSpec、风险、超时和审计契约。
7. 附件理解与证据提取：安全检查、受控解析与 Artifact/Evidence 沉淀。
8. 本地 Web 只读分析：用户授权、localhost 默认边界与越界拒绝。
9. Prompt Injection 防护：把外部内容视为不可信数据并保留风险记录。
10. 解释、验证与复现：公开任务摘要、工具日志、证据分级与报告。
11. 统一工作台：真实桌面界面及 `127.0.0.1:8080` 入口。
12. 移动端可用性：窄屏下的任务、授权、运行状态和安全边界。
13. 工程化与供应链：Docker Compose、质量门禁、依赖审计与恢复。
14. 通用评测口径：本地验收集、结构化结果、工具与证据规则。
15. 能力边界与提交：明确不提供任意 Shell、公网攻击或代替外部平台提交。

图表数据只引用实际运行记录；不展示模型隐藏思维链，只展示可公开的任务摘要、行动理由、工具日志和证据。
