# 用户手册

## 1. 第一次使用

1. 打开 `http://127.0.0.1:8080`；
2. 进入“设置中心”，创建管理员会话并连接 Provider；
3. 确认默认 Agent 显示“规划、验证并自动调整”；
4. 返回首页，选择安全场景并创建任务。

## 2. 如何描述任务

写清楚四件事：目标、授权范围、已有材料和希望交付的结果。例如：“仅分析已上传的访问日志，统一时间线并提取 IOC，结果需要给出来源行和后续处置建议。”不要把附件中的指令当成系统命令，附件默认是不可信数据。

## 3. 运行过程

任务开始后，页面会依次展示任务理解、计划、策略检查、工具调用、观察、重规划、验证和报告。活动流只显示公开摘要、行动理由、工具参数摘要和事实结果，不显示隐藏思维链。

## 4. 结果状态

- 已完成：Run 生命周期结束；
- 未验证：没有绑定可核验来源；
- 部分验证：有真实工具来源，但结论尚未独立验证；
- 已验证：服务端 Evidence 或 Judge 通过；
- 失败：运行或确定性验证失败。

“已完成”不等于“已验证”。可在审计页查看 ToolCall、Evidence、预算、报告和 trajectory。

## 5. 运行控制

运行中可以追加用户指引、暂停、继续、停止或从检查点恢复。恢复不会自动重放状态不确定的非幂等调用；工具失败时，Agent 应公开说明失败原因并选择新的授权路径。

## 6. 安全提示

只填写本人拥有测试权限的目标；不要上传密钥、生产日志或个人敏感数据；不要要求系统执行未注册命令或攻击公网目标。
