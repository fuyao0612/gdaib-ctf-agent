# 部署手册

Windows：`.\yuwang.ps1 setup`，`.\yuwang.ps1 doctor`，`.\yuwang.ps1 start`；浏览器访问 `http://127.0.0.1:8080`。停止用 `.\yuwang.ps1 stop`。开发模式和 Docker 数据目录隔离。

黄金 Web 案例：`python scripts/golden_web_lab.py --port 8088`，只绑定 127.0.0.1。演示评测使用独立 `data/golden-demo/`，结束后删除该目录即可，不触碰既有 `data/`。

正式录屏建议用 `docker compose -f compose.yaml -f compose.golden-demo.yaml up -d --build` 启动独立卷和 `18080` 端口；配置 demo Provider 后由 `scripts/run_golden_demo.py` 经正式消息入口执行案例。结束时执行同一 Compose 命令的 `down`，再显式删除 `yuwang-golden-demo_yuwang-golden-demo-data` 卷；该操作不触及默认 `yuwang_yuwang-data` 卷。
