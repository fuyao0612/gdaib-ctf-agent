# 部署手册

版本：v0.5.0 代码基线，初审封版日期：2026-09-03。默认服务只绑定 `127.0.0.1`，不应直接暴露到公网。

## 1. 前置条件

- Windows 10/11、PowerShell、Docker Desktop 和浏览器；
- 可用且已获授权的模型 Provider；
- 至少 4 GB 可用内存和足够磁盘空间。

## 2. 一键启动

```powershell
.\yuwang.ps1 setup
.\yuwang.ps1 start
.\yuwang.ps1 status
.\yuwang.ps1 doctor
```

浏览器访问 `http://127.0.0.1:8080`，健康接口为 `http://127.0.0.1:8080/api/v1/health`。

## 3. 首次配置

打开设置中心，创建管理员会话，录入 Provider API 地址、模型和密钥，点击连接测试；随后确认默认 Agent 为“规划、验证并自动调整”。密钥由服务端加密保存，前端只显示是否已配置。

## 4. 运行和停止

首页支持 CTF、应急响应、漏洞分析、静态逆向和通用研判。填写任务目标和授权范围后创建任务；运行中可暂停、继续、追加指引、查看活动流、审计时间线和报告。

```powershell
.\yuwang.ps1 stop
```

## 5. 验收

```powershell
docker compose config --quiet
docker compose up -d --build
.\yuwang.ps1 doctor
python scripts/check_tool_contracts.py
```

## 6. 数据与安全

`.env`、`data/`、数据库、日志和缓存只存在于本机，不进入提交包。公网部署必须增加 HTTPS、反向代理身份认证、限流、备份、隔离数据库和凭据轮换；当前版本默认拒绝公网目标和任意命令执行。
