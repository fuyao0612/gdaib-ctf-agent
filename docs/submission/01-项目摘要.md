# 项目摘要

## 一句话介绍

御网智元是一个面向授权附件和本地靶场的、可审计的通用网络安全智能体工作台。它将自然语言任务转换为可执行计划，按授权范围选择受控工具，保存公开行动轨迹，并用独立验证器区分“模型判断”“工具事实”和“已验证结论”。

## 解决的问题

传统安全自动化通常有两类缺陷：固定脚本只能处理预设路径；聊天式模型能够给建议，却不能稳定完成工具调用、失败调整和结果验证。御网智元将任务理解、规划、执行、观察、重规划、验证和报告固化为一个可恢复的 Run 状态机，重点解决以下问题：

- 复杂安全任务如何拆分为可执行步骤；
- 工具失败、越权或证据不足时如何安全调整路径；
- 如何让每一步行动都有公开理由和可追溯来源；
- 如何避免模型把自述文本伪装成事实或验证结果；
- 如何在单机环境中完成部署、审计、恢复和评测。

## 作品能力

- 多场景任务入口：CTF、应急响应、漏洞分析、静态逆向和通用研判；
- 默认动态 Agent：先生成 Task Brief 和计划，再执行受控工具并根据观察重规划；
- 统一工具契约：ToolSpec、Registry、PolicyEngine、Executor 和 MCP 扩展边界；
- 离线安全分析：文件元数据、文本定位、IOC、时间线、编码、哈希、JWT、PCAP 摘要等；
- 可信结果闭环：Artifact、ToolCall、EvidenceRecord、TaskResult 和独立 Judge；
- 运行可靠性：SQLite 审计、检查点恢复、上下文压缩、预算和幂等控制；
- 工程交付：Docker Compose、Windows 启动脚本、健康检查、诊断、备份和恢复。

## 可核验边界

当前版本不提供任意 Shell、公网扫描、自动攻击、多智能体协作或外部 CTF 平台提交。网络演示限定在用户明确授权的本机目标，附件和工具输出均按不可信数据处理。真实 Provider 成绩只在有可复查脱敏记录时统计，测试替身不冒充真实成绩。
