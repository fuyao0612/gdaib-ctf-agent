# 御网智元用户手册

## 使用范围
仅处理已授权附件和 localhost/127.0.0.1 靶场。系统不提供任意 Shell、未授权公网扫描、自动攻击、外部平台提交功能。

## 标准流程
1. 在设置中确认 Provider 与 Agent 状态为就绪。2. 创建任务，填写明确目标、授权范围和附件。3. 上传后核对 SHA-256、类型、注入风险与预览；附件内容不改变授权。4. 运行并查看计划、工具调用、Artifact、事件和报告。5. 以 Judge 的确定性结果和工具证据为成功依据，不以模型文字作为成功依据。

## 异常处理
Provider 未就绪时停止评测并处理本机配置；压缩包/CSV 被拒绝时缩小文件或拆分输入；安全策略拒绝时调整到明确授权范围，不绕过策略。用户确认：____________  日期：____________
