# 御网智元部署手册

版本：v0.5.0 初审冲刺版；适用范围：Windows + Docker Desktop，服务仅绑定 `127.0.0.1`。

## 前置条件
1. Docker Desktop、PowerShell、浏览器可用。2. 不提交 `.env`、Provider 密钥、`data/`、日志或数据库；使用 `.env.example` 建立本机配置。3. 仅配置参赛者已授权、已测试的 Provider。

## 默认环境
1. `./yuwang.ps1 setup` 2. `./yuwang.ps1 doctor` 3. `./yuwang.ps1 start` 4. 打开 `http://127.0.0.1:8080` 并测试 Provider。5. 使用 `./yuwang.ps1 status` 与 `./yuwang.ps1 stop`。

## 隔离黄金环境
1. `docker compose -f compose.yaml -f compose.golden-demo.yaml up -d --build`。2. 打开 `http://127.0.0.1:18080`，在独立卷中配置并测试 Provider。3. `python scripts/init_golden_cases.py`，对 A/B/C 各三次执行 `python scripts/run_golden_demo.py --case <案例> --timeout 240`。4. 导出评测统计、轨迹和报告。停止：`docker compose -f compose.yaml -f compose.golden-demo.yaml down`。
