# 御网智元部署手册

版本：v0.5.0 初审冲刺版；适用范围：Windows + Docker Desktop，服务仅绑定 `127.0.0.1`。

## 前置条件
1. Docker Desktop、PowerShell、浏览器可用。2. 不提交 `.env`、Provider 密钥、`data/`、日志或数据库；使用 `.env.example` 建立本机配置。3. 仅配置参赛者已授权、已测试的 Provider。

## 默认环境
1. `./yuwang.ps1 setup` 2. `./yuwang.ps1 doctor` 3. `./yuwang.ps1 start` 4. 打开 `http://127.0.0.1:8080` 并测试 Provider。5. 使用 `./yuwang.ps1 status` 与 `./yuwang.ps1 stop`。

## 演示与评测
演示、任务执行和评测均使用同一 `http://127.0.0.1:8080` 工作台。录制前备份现有数据并清理无关任务，配置和测试 Provider；使用评测中心导出脱敏统计、轨迹和报告。不得把 `.env`、数据库、密钥或未脱敏日志放入提交包。
