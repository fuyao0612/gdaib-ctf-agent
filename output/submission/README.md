# 御网智元初审材料

## 建议阅读顺序

1. `御网智元-方案介绍.pdf`：15 页作品概览。
2. `御网智元-技术报告.pdf`：完整技术路线、架构、安全边界和工程证据。
3. `御网智元-方案设计文档.pdf`：设计目标、模块划分和关键流程。
4. `御网智元-测试与评测报告.pdf`：自动化测试、工具契约、Docker 和界面验收结果。
5. `御网智元-用户手册.pdf`：首次启动、Provider/Agent 配置和任务执行。
6. `御网智元-开发文档.pdf`：本地开发、测试门禁和扩展入口。

DOCX 版便于按主办方模板调整，PPTX 版便于现场讲解；同名 PDF 为建议审阅版。Markdown 文件是可检索的源材料和补充证据。

## 程序验收

在 Windows PowerShell 中执行：

```powershell
.\yuwang.ps1 setup
.\yuwang.ps1 doctor
.\yuwang.ps1 start
```

打开 <http://127.0.0.1:8080>。完整质量检查使用 `.\yuwang.ps1 check`。
